# サンプル

ANUI のエレメントを組み合わせて実際のメニューを作る、そのままコピーして使えるレシピ集。それぞれエグゼキュータに貼り付けてすぐ動かせる、独立したスクリプトです。

## レシピ

- **[基本メニュー](/ja/examples/basic-menu)** —— 出発点となるメニュー。ウィンドウ、いくつかのタブ、よく使うエレメント（Toggle、Slider、Dropdown、Button、Keybind、Paragraph）の組み合わせと通知。
- **[設定システム](/ja/examples/config-system)** —— Flag 付きエレメントでユーザー設定を保存・読み込みし、ディスクから一覧を作る設定ピッカーと自動読み込みの Toggle を用意します。
- **[カテゴリーページ](/ja/examples/category-pages)** —— [Category](/ja/elements/category) エレメントで、1 つのタブの中に表示 / 非表示式の「ページ」を作ります。

::: tip 完全なデモスクリプト
これらのレシピは分かりやすさのために削ぎ落としてあります。すべてのエレメントと機能を組み込んだ公式の完全なデモは、リポジトリの `main_example.lua` として [GitHub](https://github.com/ANHub-Script/ANUI) にあります。
:::
