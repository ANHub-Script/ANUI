# 示例

可直接复制粘贴的完整实用方案，把 ANUI 元素组合成真实可用的菜单。每一个都是独立的脚本，可以直接丢进执行器里运行。

## 实用方案

- **[基础菜单](/zh/examples/basic-menu)** —— 一个入门菜单：一个窗口、几个标签页，以及常见元素的组合（Toggle、Slider、Dropdown、Button、Keybind、Paragraph），外加一条通知。
- **[配置系统](/zh/examples/config-system)** —— 用带 Flag 的元素保存并加载用户设置，从磁盘填充配置选择器，还有一个自动加载开关。
- **[分类页面](/zh/examples/category-pages)** —— 用 [Category](/zh/elements/category) 元素在单个标签页内构建可显示/隐藏的"页面"。

::: tip 完整演示脚本
这些实用方案为了简洁做了精简。完整的官方演示 —— 每个元素与功能都完整接好 —— 位于仓库中的 `main_example.lua`，见 [GitHub](https://github.com/ANHub-Script/ANUI)。
:::
