# Элементы

Элементы — это интерактивные элементы управления внутри вашего окна: button, toggle, slider, dropdown и другие. Они всегда создаются из **контейнера**: Tab, Section или Group.

## Создание элементов

Каждый элемент создаётся вызовом метода у контейнера. Самый распространённый контейнер — Tab:

```lua
local ANUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/ANHub-Script/ANUI/refs/heads/main/dist/main.lua"))()

local Window = ANUI:CreateWindow({ Title = "My Hub", Folder = "MyHub" })

-- 1. Создайте контейнер (Tab)
local myTab = Window:Tab({ Title = "Main", Icon = "house" })

-- 2. Создайте элементы внутри него
myTab:Button({ Title = "Click me", Callback = function() end })
myTab:Toggle({ Title = "Auto Farm", Callback = function(state) end })
```

`Section` и `Group` тоже являются контейнерами — они предоставляют **те же** методы создания элементов, что и Tab, поэтому вы можете вкладывать элементы друг в друга, чтобы упорядочить макет:

```lua
local section = myTab:Section({ Title = "Combat" })
section:Toggle({ Title = "God Mode", Callback = function(state) end })

local row = myTab:Group({})       -- располагает дочерние элементы по горизонтали
row:Button({ Title = "Save" })
row:Button({ Title = "Load" })
```

::: tip
Каждый метод создания элемента возвращает модуль, у которого можно вызывать методы (напр. `local t = myTab:Toggle({...})`, затем `t:Set(true)`). Сохраните возвращённое значение, если планируете обновлять элемент позже.
:::

## Общая база

Большинство интерактивных элементов построено на одной и той же базе, поэтому они используют общий набор полей конфигурации и методов. Изучите их один раз — и они пригодятся везде.

### Общая конфигурация

| Field | Type | Default | Описание |
| --- | --- | --- | --- |
| `Title` | `string` | имя элемента | Основная подпись. Поддерживает [токены rich-text](#rich-text-в-title-desc). |
| `Desc` | `string` | `nil` | Дополнительная строка описания. Поддерживает токены rich-text, `\n` и `\t`. |
| `Icon` | `string` | зависит от элемента | Имя иконки (Lucide) или `rbxassetid://…`. |
| `Image` | `string` \| `table` | `nil` | Изображение с выравниванием по левому краю (asset id или таблица карточки). |
| `ImageSize` | `number` | `30` | Размер левого изображения, в пикселях. |
| `Thumbnail` | `string` | `nil` | Большое изображение-миниатюра. |
| `ThumbnailSize` | `number` | `80` | Размер миниатюры, в пикселях. |
| `IconThemed` | `boolean` | `false` | Окрашивает иконку в текущий цвет темы. |
| `Color` | `Color3` \| `string` | `nil` | Цветной фон (имя темы или `Color3`); цвет текста подбирается автоматически. |
| `Justify` | `string` | `"Between"` | Выравнивание содержимого внутри строки элемента. |
| `Locked` | `boolean` | `false` | Отображает оверлей блокировки и блокирует взаимодействие. |
| `Buttons` | `table` | `nil` | Встроенные кнопки, отображаемые в строке элемента (см. ниже). |
| `TitleGradient` | `table` | `nil` | Градиент, применяемый к тексту заголовка. |
| `DescGradient` | `table` | `nil` | Градиент, применяемый к тексту описания. |

### Общие методы

Эти методы доступны у большинства интерактивных элементов:

- `:SetTitle(text)` — обновляет заголовок.
- `:SetDesc(text)` — обновляет описание.
- `:SetIcon(icon)` / `:SetImage(image)` — обновляет иконку или изображение.
- `:Lock(text?)` — блокирует элемент (при желании с текстом оверлея).
- `:Unlock()` — снимает блокировку элемента.
- `:Highlight()` — кратко подсвечивает элемент, чтобы привлечь внимание.
- `:Destroy()` — удаляет элемент.
- `:SetButtons(buttons)` / `:GetButton(key)` / `:GetButtons()` — управляет встроенными кнопками.

::: info
Отдельные элементы добавляют свои методы поверх общей базы — например, `Toggle:Set(...)`, `Slider:SetMax(...)` или `Dropdown:Refresh(...)`. Полный список смотрите на странице каждого элемента.
:::

## Rich text в Title & Desc

`Title` и `Desc` принимают встроенные токены, которые позволяют вставлять иконки, изображения, градиенты и даже кнопки прямо в текст:

- **Встроенные иконки** — `{icon}` или `{name}`, с необязательным размером: `{icon:star size=28}`.
- **Встроенные изображения** — просто вставьте ссылку `rbxassetid://…` прямо в строку.
- **Градиенты** — оберните текст в `<gradient>…</gradient>` или укажите цвета и поворот: `<gradient=#40c9ff,#e81cff|45>…</gradient>`.
- **Встроенные кнопки** — `<button=key>Label</button>` или краткая форма `{button:key}`, связанные с записями в map `Buttons` элемента.

`Desc` дополнительно поддерживает:

- `\n` — многострочные описания.
- `\t` — строку из двух колонок (подпись слева, значение справа).

```lua
myTab:Button({
    Title = "Status: <gradient=#30FF6A,#e7ff2f>Online</gradient> {check}",
    Desc = "Ping\t24ms\nRegion\tSEA",
})
```

## Сохранение конфигурации через Flag

Элементы с состоянием — **Toggle**, **Slider**, **Dropdown**, **Input**, **Keybind** и **Colorpicker** — принимают поле `Flag`. Элемент с флагом автоматически регистрируется в активной конфигурации, поэтому его значение сохраняется и восстанавливается между сессиями.

```lua
myTab:Toggle({ Title = "Auto Farm", Flag = "AutoFarm", Callback = function(state) end })
```

Полное описание процесса смотрите в разделе [Конфигурация и флаги](/ru/features/config-and-flags).

## Все элементы

| Элемент | Описание |
| --- | --- |
| [Button](/ru/elements/button) | Строка действия, по которой можно щёлкнуть, с необязательной иконкой и встроенными кнопками. |
| [Toggle](/ru/elements/toggle) | Переключатель on/off или checkbox, сообщающий boolean. |
| [Slider](/ru/elements/slider) | Перетаскиваемый числовой слайдер с необязательным шагом и ручным вводом. |
| [Dropdown](/ru/elements/dropdown) | Список с одиночным или множественным выбором; может работать и как меню действий. |
| [Input](/ru/elements/input) | Однострочное или многострочное текстовое поле. |
| [Keybind](/ru/elements/keybind) | Привязывает действие к клавише, срабатывая глобально при нажатии. |
| [Colorpicker](/ru/elements/colorpicker) | Выбирает цвет (с необязательной прозрачностью) через диалог. |
| [Paragraph](/ru/elements/paragraph) | Блок форматированного текста с необязательными карточками изображений и кнопками в стопке. |
| [Code](/ru/elements/code) | Блок с фрагментом кода, который можно скопировать. |
| [Section](/ru/elements/section) | Складываемый контейнер, группирующий дочерние элементы под заголовком. |
| [Divider](/ru/elements/divider) | Горизонтальная (или вертикальная, внутри Group) разделительная линия. |
| [Space](/ru/elements/space) | Невидимый разделитель для вертикального отступа. |
| [Image](/ru/elements/image) | Самостоятельное изображение с управлением соотношением сторон и масштабированием. |
| [Group](/ru/elements/group) | Контейнер, располагающий дочерние элементы по горизонтали. |
| [Category](/ru/elements/category) | Горизонтальная полоса опций для переключения между группами элементов. |
