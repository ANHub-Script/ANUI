# Image

Самостоятельный элемент-изображение с управлением соотношением сторон, масштабированием и радиусом углов. Используйте его для показа баннеров, иконок, предпросмотров или любого декоративного оформления внутри вкладки.

## Базовое использование

```lua
local myTab = Window:Tab({ Title = "Main", Icon = "house" })

myTab:Image({
    Image = "rbxassetid://84366761557806",
    AspectRatio = "16:9",
})
```

## Конфигурация

| Field | Type | Default | Описание |
| --- | --- | --- | --- |
| `Image` | `string` | `""` | Ресурс изображения для отображения: `rbxassetid://…` (или URL, если исполнитель это поддерживает). |
| `AspectRatio` | `string` | `"16:9"` | Соотношение ширины к высоте, напр. `"16:9"` или `"4:3"`. Задайте `"native"`, `"original"` или `"auto"`, чтобы использовать реальные размеры изображения. |
| `Radius` | `number` | `—` | Радиус углов элемента-изображения. |
| `ScaleType` | `string` | `"Fit"` | Как изображение заполняет свой фрейм: `"Fit"` вписывает его целиком (letterbox); `"Crop"` заполняет полностью и обрезает. |
| `Crop` | `boolean` | `false` | Сокращение для `ScaleType = "Crop"`. |
| `Native` / `KeepAspect` | `boolean` | `false` | Использовать исходный размер изображения / сохранять его настоящее соотношение сторон. |
| `NativeSize` | `Vector2` | `—` | Явный исходный размер в пикселях, используется вместе с обработкой native/соотношения сторон. |
| `Height` | `number` | `—` | Фиксированная высота в пикселях; ширина следует соотношению сторон. |
| `Size` | `UDim2` | `—` | Явный размер, который переопределяет `AspectRatio` и `Height`. |

## Методы

### `Image:SetSize(size)`

Изменяет размер изображения. Передайте `UDim2` для явного размера или число, чтобы задать фиксированную высоту в пикселях.

```lua
img:SetSize(UDim2.fromOffset(200, 200))
img:SetSize(120) -- высота в пикселях
```

### `Image:SetScaleType(type)`

Устанавливает тип масштабирования: `"Fit"` или `"Crop"`.

```lua
img:SetScaleType("Crop")
```

### `Image:SetAspectRatio(ratio)`

Устанавливает соотношение сторон. Принимает строку соотношения, например `"16:9"`, либо `"native"` / `"original"` / `"auto"` для настоящего соотношения изображения.

```lua
img:SetAspectRatio("4:3")
img:SetAspectRatio("native")
```

### `Image:GetNativeSize()`

Возвращает исходный размер изображения в пикселях как `Vector2`.

```lua
local size = img:GetNativeSize()
print(size.X, size.Y)
```

### `Image:Destroy()`

Удаляет элемент-изображение.

```lua
img:Destroy()
```

## Примеры

### Изображение 16:9 по asset id

```lua
myTab:Image({
    Image = "rbxassetid://84366761557806",
    AspectRatio = "16:9",
    Radius = 12,
})
```

### Изображение с исходным соотношением сторон

Позвольте изображению сохранить его настоящие пропорции, задав `AspectRatio = "native"`.

```lua
myTab:Image({
    Image = "rbxassetid://84366761557806",
    AspectRatio = "native",
})
```

### Обрезанный квадрат через Size

Задайте изображению явный квадратный `Size` и обрежьте его, чтобы оно полностью заполнило фрейм.

```lua
myTab:Image({
    Image = "rbxassetid://84366761557806",
    Size = UDim2.fromOffset(120, 120),
    ScaleType = "Crop", -- или Crop = true
})
```
