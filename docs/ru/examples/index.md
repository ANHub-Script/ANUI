# Примеры

Готовые рецепты, которые можно вставить как есть: они собирают элементы ANUI в настоящие меню. Каждый из них — самостоятельный скрипт, который можно закинуть в свой исполнитель и запустить.

## Рецепты

- **[Базовое меню](/ru/examples/basic-menu)** — стартовое меню: окно, пара вкладок и набор часто используемых элементов (Toggle, Slider, Dropdown, Button, Keybind, Paragraph) плюс уведомление.
- **[Система конфигурации](/ru/examples/config-system)** — сохраняйте и загружайте настройки пользователя через элементы с флагами, выбор конфигурации из списка на диске и toggle авто-загрузки.
- **[Страницы категорий](/ru/examples/category-pages)** — соберите «страницы» с показом/скрытием внутри одной вкладки с помощью элемента [Category](/ru/elements/category).

::: tip Полный демо-скрипт
Эти рецепты урезаны для наглядности. Полная официальная демонстрация — со всеми элементами и возможностями — лежит в репозитории как `main_example.lua` на [GitHub](https://github.com/ANHub-Script/ANUI).
:::
