# Установка

ANUI подключается всего одной строкой — без загрузок и без зависимостей. Вставьте её в начало своего скрипта, и можно приступать к сборке.

## Подключение

```lua
local ANUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/ANHub-Script/ANUI/refs/heads/main/dist/main.lua"))()
```

### Что делает эта строка

- `game:HttpGet(url)` скачивает свежий исходник ANUI с GitHub в виде строки.
- `loadstring(...)` компилирует эту строку в функцию, готовую к запуску.
- Завершающие `()` вызывают её и возвращают таблицу библиотеки ANUI.
- Результат сохраняется в local с именем `ANUI` — каждый пример на этом сайте вызывает методы у этой переменной (`ANUI:CreateWindow`, `ANUI:Notify` и так далее).

::: tip Cache-busting при разработке
Некоторые исполнители кешируют ответы `HttpGet`, поэтому во время работы вам может продолжать приходить старая сборка. Добавьте случайную query-строку, чтобы принудительно получить свежую копию:

```lua
local ANUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/ANHub-Script/ANUI/refs/heads/main/dist/main.lua?v="..math.random()))()
```

Уберите часть `?v=`... в продакшене, чтобы ответ мог кешироваться как обычно.
:::

## Проверка загрузки

Выведите версию, чтобы убедиться, что библиотека доступна:

```lua
print(ANUI.Version)
```

Если вы видите строку версии, значит ANUI загрузился правильно.

::: warning Требования к исполнителю
ANUI нужен исполнитель с поддержкой `loadstring` и `game:HttpGet`.

Сохранение конфигураций и опция `SaveKey` в системе ключей дополнительно требуют файловых глобальных функций `readfile`, `writefile`, `isfile` и `makefolder`. Без них UI всё равно работает — недоступно лишь сохранение на диск.
:::

## Устранение неполадок

::: details ANUI равен `nil` / "attempt to call a nil value"
`loadstring` или `HttpGet` ничего не вернули. Убедитесь, что ваш исполнитель поддерживает и то, и другое, и что он не блокирует домен `raw.githubusercontent.com`. Запустите заново, добавив cache-busting-запрос `?v=`, показанный выше.
:::

::: details HttpGet отключён / запросы не проходят
Некоторые исполнители управляют HTTP-запросами через настройку. Включите HTTP / HttpGet в своём исполнителе, затем запустите скрипт снова.
:::

::: details На экране ничего не появляется
Загрузка библиотеки сама по себе ничего не отрисовывает. Убедитесь, что вы действительно создаёте окно — см. [Быстрый старт](/ru/guide/getting-started).
:::
