# Contoh

Resep siap-tempel yang menggabungkan elemen ANUI menjadi menu nyata. Masing-masing adalah script mandiri yang bisa langsung Anda tempel ke executor dan jalankan.

## Resep

- **[Menu Dasar](/id/examples/basic-menu)** — Menu awal: sebuah window, beberapa tab, dan campuran elemen umum (Toggle, Slider, Dropdown, Button, Keybind, Paragraph) plus sebuah notifikasi.
- **[Sistem Konfigurasi](/id/examples/config-system)** — Simpan dan muat pengaturan pengguna dengan elemen ber-flag, pemilih config yang diisi dari disk, dan toggle auto-load.
- **[Halaman Kategori](/id/examples/category-pages)** — Bangun "halaman" show/hide di dalam satu tab dengan elemen [Category](/id/elements/category).

::: tip Skrip demo lengkap
Resep ini dipangkas agar ringkas. Demo resmi yang lengkap — dengan setiap elemen dan fitur terpasang — ada di repositori sebagai `main_example.lua` di [GitHub](https://github.com/ANHub-Script/ANUI).
:::
