# Examples

Complete, copy-paste recipes that combine ANUI elements into real menus. Each one is a self-contained script you can drop into your executor and run.

## Recipes

- **[Basic Menu](/examples/basic-menu)** — A starter menu: a window, a couple of tabs, and a mix of common elements (Toggle, Slider, Dropdown, Button, Keybind, Paragraph) with a notification.
- **[Config System](/examples/config-system)** — Save and load user settings with flagged elements, a config picker populated from disk, and an auto-load toggle.
- **[Category Pages](/examples/category-pages)** — Build show/hide "pages" inside a single tab with the [Category](/elements/category) element.

::: tip Full demo script
These recipes are trimmed for clarity. The complete, official demo — every element and feature wired up — lives in the repository as `main_example.lua` on [GitHub](https://github.com/ANHub-Script/ANUI).
:::
