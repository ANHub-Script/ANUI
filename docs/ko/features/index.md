# 기능

ANUI는 UI 요소 외에도 상태 관리, 테마, 알림, 다국어, 스케줄러 등의 기능을 제공합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| [Notifications](./notifications) | Toast 알림 표시 |
| [Dialogs & Popups](./dialogs-and-popups) | 확인창과 독립형 모달 |
| [Config & Flags](./config-and-flags) | UI 상태 저장/복원 |
| [Key System](./key-system) | 키 기반 접근 제어 |
| [Themes](./themes) | 26개 내장 테마 및 Custom Theme |
| [Localization](./localization) | 다국어 UI 구성 |
| [Scheduler](./scheduler) | 관리형 Loop와 자동 정리 |
| [Open Button](./open-button) | 닫힌 Window 다시 열기 |

각 기능은 기존 ANUI API를 그대로 사용하므로 코드 구조를 크게 바꿀 필요가 없습니다.
