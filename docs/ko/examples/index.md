# 예제

ANUI 요소를 실제 메뉴로 결합하는 완전한 복사-붙여넣기 레시피입니다. 각 예제는 실행기에 그대로 넣고 실행할 수 있는 독립 실행형 스크립트입니다.

## 레시피

- **[기본 메뉴](/examples/basic-menu)** — 시작용 메뉴입니다: 창 하나, 탭 몇 개, 그리고 일반적인 요소(Toggle, Slider, Dropdown, Button, Keybind, Paragraph)의 조합과 알림을 포함합니다.
- **[설정 시스템](/examples/config-system)** — 플래그가 지정된 요소, 디스크에서 채워지는 설정 선택기, 자동 로드 토글로 사용자 설정을 저장하고 불러옵니다.
- **[카테고리 페이지](/examples/category-pages)** — [Category](/elements/category) 요소로 단일 탭 안에 표시/숨김 "페이지"를 만듭니다.

::: tip 전체 데모 스크립트
이 레시피들은 명확성을 위해 축약되었습니다. 모든 요소와 기능이 연결된 완전한 공식 데모는 저장소의 `main_example.lua`에 [GitHub](https://github.com/ANHub-Script/ANUI)에서 확인할 수 있습니다.
:::
