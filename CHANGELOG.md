# Changelog

All notable changes to ANUI are documented here.

The format follows the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), with releases published from Git tags such as `v1.0.289`.

## [Unreleased]

### Changed

## [1.0.288]

### Current baseline

- 15+ UI elements.
- 26 built-in themes.
- Config and flags system.
- Key system with supported providers.
- Localization support.
- Scheduler and loop utilities.
- VitePress documentation with multiple languages.
- GitHub Pages documentation deployment.

> Earlier project history predates the current curated changelog format. Future releases will be added here automatically as the release workflow is adopted.

## Release categories

Use these headings when preparing release notes:

- **Added** — new features or APIs.
- **Changed** — improvements or behavior changes.
- **Fixed** — bug fixes.
- **Deprecated** — features planned for removal.
- **Removed** — removed features or APIs.
- **Security** — security-related changes.

## Versioning

ANUI follows semantic-style versioning:

`MAJOR.MINOR.PATCH`

- **MAJOR** — breaking API or behavior changes.
- **MINOR** — backwards-compatible features.
- **PATCH** — backwards-compatible fixes and small improvements.

For published versions, see the [GitHub Releases](https://github.com/ANHub-Script/ANUI/releases) page.
